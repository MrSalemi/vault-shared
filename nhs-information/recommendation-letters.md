# Recommendation letters — Natick High School

A standing fact. Present tense. If it becomes wrong, edit this file.

## When

The first half-day in October is for writing recommendation letters. Ray
gives that afternoon to them.

Find the day in the early release table of the year's schedule calendar, in
this folder. In 2026-2027 it is Wednesday, October 7, 2026.

## The tasks, every year

| Task | When |
| ---- | ---- |
| Update recommendation form | The beginning of the school year. The form is ready before the first student asks. |
| Send recommendation form to students who ask | As each student asks, from the start of school until the half-day. |
| Review Naviance for the list of students who need recommendations | Before the half-day, so the list is in hand when the writing starts. |

These are tasks in Things 3. Make them for the new year when the new
calendar is out. Work the half-day out from that calendar. Never copy last
year's date.

## Student information

The Naviance list is names. It stays in Naviance. No student's name goes in a
task title, a report or the Drive Life folder. See `teaching-schedule.md`,
"Student information".

## Not the same thing

"Create Class Recommendations" in Things is course placement in PowerSchool.
It is a different job from these letters.

Ray on 2026-10-07, the first October half-day of 2026-2027. He made the three

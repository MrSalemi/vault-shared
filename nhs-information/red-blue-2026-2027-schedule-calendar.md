## Column legend (from row 1 of the source file)

| Column | Header |
|---|---|
| A | Column 1 |
| B | Schedule |
| C | Notes |
| D | Physics Blue 2 |
| E | Physics Red 2 |
| F | Physics Red 3 |
| G | Robotics Red 1 |
| H | Engineering Blue 1 |

Column B carries the day's cycle code (`R1`/`R2`/`B1`/`B2`) or a named non-cycle day (holiday, break, etc. — see below). Columns D-H are per-course/section columns; their header names (e.g. "Robotics Red 1") pair a course with the cycle day it meets on. Cell values in those columns are event notes (due dates, exams, "Out of School") for that course on that date, not attendance records — the meaning of the R/B cycle numbering itself isn't stated in the file and should be confirmed if it matters.

Note: `Robotics Red 1`'s tracked events stop after "End of Term 1" (2026-10-30) — the source file doesn't have later-term robotics due dates filled in, whether because they're not scheduled yet or just not entered.

Note: two "Last Day of School" entries appear (2027-06-11 and 2027-06-21) — likely an earliest-possible date and a snow-day contingency date, standard for MA school calendars, but not stated explicitly in the file.

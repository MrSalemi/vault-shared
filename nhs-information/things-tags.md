A standing fact. Present tense. If it becomes wrong, edit this file.

| Tag | Shortcut | What |
| --- | -------- | ---- |
| Physics R03 | `3` | Physics Red 3 |
| Physics R02 | `2` | Physics Red 2 |
| Physics B02 | `b` | Physics Blue 2 |

These are the complete set. There are no other tags in Things 3.

## How the shortcuts work

A shortcut is one character, typed in Things' tag picker.

The two red Physics sections use digits — `3` and `2` — matching the block
number in the tag name. Blue is `b`.

Engineering is `z`, not `e`. Robotics is `q`, not `r`.

## Why the names are what they are

The tag names match the class tags in Ray's "New Assignment" Apple Shortcut, so
one vocabulary covers both. RoboNatick has no counterpart in the Shortcut,
because it is a program and not a class.

Physics is tagged by section, not by day color. Red 2 and Red 3 run in
lockstep — same lesson, taught twice on a Red day — but they are graded and
tracked separately, so they get separate tags.

Barely. As of 2026-09-07 exactly one item in the database carries a tag:
"Initialize all the robots", tagged Robotics, inside the `[Template] Prepare
for Semester` project. The tags are set up and ready rather than in service.
